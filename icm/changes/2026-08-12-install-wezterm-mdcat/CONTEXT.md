# Configuration change — install WezTerm and mdcat
One job: provide a four-stage, human-reviewed change record.

## Inputs
- Shared targets: `../../_shared/targets.md`.
- Safety rules: `../../_shared/safety.md`.
- External-source policy: `../../_shared/external-sources.md` when importing prior configuration.

## Process
1. Copy this folder to `../../changes/YYYY-MM-DD-change-name/`.
2. Work through `01_investigate/` to `04_deploy/` in order.
3. Replace placeholder text and preserve all output files as the record of the change.

## Outputs
- A complete reviewed record alongside the applied configuration change.

## Human check
Review each numbered stage output before starting the next one.
